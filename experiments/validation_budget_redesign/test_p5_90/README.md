# Test 补充评价 · P5／90 去重共享

在本轮加载 Test 前，冻结于 2026-11-22T17:33:44+08:00。G、L 和 100 套 A1 各有 90 个不同的无向品类组合，规则来源、归属与所保留的方向来自冻结 Discovery 清单，所有主样本订单均可匹配对应系统的共享规则。本轮沿用已对原 P5／100 限群方案公布结果的历史 Test 时段，作为新口径的补充评价。

Test 时段为 2011‑06‑01 至 2011‑12‑01（不含结束日）。主比较纳入 **5,730 张订单、1,510 名历史顾客**，占全部 10,890 单的 **52.62%**。其余 5,160 单用 G90 全局回退，共购覆盖 **4,013 单（77.77%）**。
