# 1122 实验方案与结果汇总

范围为 1122 文件夹内的原始三路线、三项追加实验，以及最后两轮融合与时间实验。表中百分比保留两位小数，pp 为百分点。新增、丢失、净增均指与表中对照在同一批订单上的命中变化。订单分层、逐随机种子和调参网格保留为表后链接。

## 0．样本、时间和核验

所有训练与评价订单早于 2011‑06‑01，分析中的最后一张订单发生于 2011-05-31 15:53:00。正式 Test 未运行。预处理使用清洗快照 2ae672b7 和冻结 taxonomy_v1，682,047 行有效销售明细、5,835 张有顾客 ID 的历史取消发票，无法映射的有效销售行数为 0。
