高金额订单补充分析

仅使用Discovery历史已知顾客订单。全体Discovery金额90%分位数为£888.47，采用≥门槛并保留并列：753张订单、310名顾客，贡献42.51%的毛购买金额。原有G/L/R实验未修改。

主要发现

  • 高金额订单中纸杯蛋糕托、午餐盒、蛋糕架和茶杯套装的共购较突出。
  • 生成1128条合格方向规则；原有相对支持度1%、联合和前件至少20次、confidence≥0.2、lift≥1不变。因此高金额样本实际支持度门槛约2.66%。该门槛不是Validation选出的最优设置。
  • 例：粉色佩斯利蛋糕纸杯→波点蛋糕纸杯，高金额订单support 9.03%、其余2.13%；confidence 70.83%对52.94%，联合68次。
  • 篮子大小影响明显：高金额篮商品种类中位数29，其余14。第一条蛋糕纸杯规则在21–50种商品的篮中仍有差异（support 11.94%对4.02%，confidence 78.05%对56.59%），但51种及以上篮中confidence接近（63.41%对61.54%）。这只是粗分层，不能证明排除了混杂。
  • C0/C1/C2分别有53/99/601张高金额订单；小群不单独调低门槛追求规则。case_cluster_counts.csv给出案例群体分布。

解释边界

按最终订单金额筛选属于事后描述，不能用于声称预测订单是否高金额。单价、数量和商品种类都可能贡献高金额。匹配规则的整单金额不是该规则创造的销售额，多条规则金额不能直接相加。高金额订单与其余订单样本量不同；本补充不是新的G/L/R公平效果实验，未评价Validation/Test。

核验：Top50独立集合计数通过；原始规则证据、选中规则和manifest哈希未变。输入版本、阈值及时间记录在manifest.json。原始数据含顾客标识，所有文件仅本地保存。
