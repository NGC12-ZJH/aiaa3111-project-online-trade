# 品类层固定系统预算 G/L/R 比较

严格档：support≥3%，联合及前件次数≥20，confidence≥50%，lift≥1.5；三品类额外要求confidence增量≥5个百分点。Discovery开发配置，未经Validation选择。二/三品类混合排序，未设置长度配额。

系统总预算B=20/50/100。G独占B；L及每个随机种子按其组内Discovery订单数用最大余数法分配，平局按group_id，不转移剩余名额。每个组按联合次数↓、confidence↓、lift↓、rule_id↑取规则。不同群同一规则各占一个部署名额；反向规则各占名额，不额外做组合去重。所有系统实际名额均等于B。

群内规则仅用于对应群的订单。系统覆盖率为完整包含至少一条被部署规则的订单并集÷7521；前件触达率另列，不是预测准确率或未来表现。每个随机种子产生一个全系统指标，20次重复，不把60组当独立样本。

## 输出

system_metrics.csv：每个系统及随机种子的覆盖、触达与去重数量；allocation_audit.csv：各组配额及命中数；selected_rules.csv：实际部署规则；order_coverage.csv.gz：逐订单命中及分组，可复核比较。

规则用同一Discovery数据选取并评估，属于开发期描述。L超过若干随机种子不是显著性检验。结果仅代表当前配置、预算分配和排序，不能推出其他策略的优劣。
