# 品类层三档筛选与三品类增量检查

仅筛选已有Discovery证据，不重新挖掘，不使用Validation/Test。三档support/confidence/lift依次为：基线1%/20%/1；中等2%/40%/1.3；严格3%/50%/1.5；联合及前件次数均≥20。

每档分别报告不检查增量、三品类增量≥5个百分点。增量为confidence(AB→C)−max(confidence(A→C),confidence(B→C))，直接使用共同池中单前件证据，即使单前件规则未合格也参与比较。二品类不做该增量筛选。它不是统计显著性检验。

订单覆盖率＝至少完整包含一条保留规则全部品类的订单数÷本范围全部订单数；另列前件触达率。使用全部保留规则，不是TopK或系统预算。不同组合数对前后件并集去重。三品类指3个不同l2。

热门品类按各范围订单出现率取Top10（同率按类别代码排序）。报告保留组合中全部商品均属于热门Top10的比例、覆盖子类数和最集中子类占组合的比例；以不同组合计数避免正反规则重复影响。不设任意阈值把结果判为仅剩热门。

随机结果先在每个seed内对3组取等权均值，再汇总20个seed，不将60组当独立样本。零规则时覆盖率为0，集中度未定义留空。

## 文件说明

scope_rules/：原基线合格规则及三档通过标记、增量值及两个单前件置信度和ID。scope_summary.csv：全部64范围×3档×2增量方案×3长度口径。top50.csv：各配置独立Top50。category_concentration.csv：各范围保留组合的高频子类。random_seed_means.csv：按种子聚合；随机均值不代表合并订单覆盖率。

这些结果用于Discovery敏感性分析。规则数量和覆盖率不能独自决定最终参数，下一步需Validation验证；未据此作显著性或业务增益结论。
