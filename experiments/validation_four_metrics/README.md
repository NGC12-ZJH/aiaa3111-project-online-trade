# Validation 四类指标对照

使用原来冻结的 P1–P5 和 20／50／100 条规则预算。比较 G 全局、L 真实分群的限群与共享口径，以及 100 个活跃度匹配随机分组 A1。规则外推到 4,862 张合格 Validation 订单。遮挡实验使用其中有至少两个不同品类的 4,311 单。此次结果属于冻结后的补充诊断。

## 一、预测准不准

下表预算为 100，每格按 G / L 限群排列。

| 配置 | 触发准确率 | Hit@5 | NDCG@5 |
| --- | ---: | ---: | ---: |
| P1 | 29.78% / 34.27% | 23.54% / 19.69% | 0.159 / 0.135 |
| P2 | 38.95% / 39.14% | 20.81% / 17.42% | 0.149 / 0.128 |
| P3 | 45.69% / 46.68% | 14.68% / 11.25% | 0.117 / 0.095 |
| P4 | 38.80% / 39.18% | 21.32% / 17.37% | 0.151 / 0.128 |
| P5 | 38.47% / 38.88% | 22.08% / 17.44% | 0.155 / 0.128 |

P3 的触发准确率最高，但在全部遮挡订单上的 Hit@5 最低。Discovery 热门品类基线的 Hit@5 是 **25.31%**、NDCG@5 是 **0.164**。本轮 G/L 规则库在三个预算上的 Hit@5 均低于该基线。热门基线可在每单给足五项，规则法允许推荐列表不足五项。报告同时提供实际发出条数准确率、推荐覆盖和固定五位的 Precision@5。

- 触发准确率按订单与推荐后件去重。相同订单中，多条规则推荐同一后件只算一次。分母为全部触发的订单与后件对，分子为后件实际出现的对。
- 遮挡用带固定盐值的订单编号哈希，每单遮住同一个品类。过滤篮里已见品类后，推荐按 Discovery confidence、联合次数、Lift 降序与规则编号、群编号升序排。同一后件取排名最靠前的触发。Top‑K 的分母包括可遮挡但没有给出推荐的订单。
- Hit@5 等于单目标 Recall@5。固定槽位 Precision@5 等于总命中数除以五倍订单数。NDCG@5 进一步考虑遮挡品类被排在第几。热门品类按 Discovery 的出现订单数排序。

## 二、控制后件热门程度

| 配置 | Added Value 中位 · pp | Lift 中位 | IDF 加权覆盖 |
| --- | ---: | ---: | ---: |
| P1 | +10.78 / +10.87 | 1.428 / 1.342 | 42.87% / 33.03% |
| P2 | +18.08 / +14.64 | 1.573 / 1.487 | 36.88% / 31.37% |
| P3 | +23.53 / +22.94 | 1.689 / 1.676 | 32.29% / 27.22% |
| P4 | +17.43 / +14.64 | 1.550 / 1.487 | 37.58% / 31.37% |
| P5 | +17.41 / +14.33 | 1.541 / 1.487 | 38.47% / 31.61% |

- Added Value 为 Validation 置信度减去同一评价范围的后件基础出现率。Lift 为两者之比。中位数及四分位按可估规则计算，CSV 列出有效数量。两者都是观察性关联。
- IDF 使用 Discovery 的 -log((后件订单数 + 1)/(Discovery 总订单数 + 1))。每单若命中多个后件，取最高后件 IDF 一次。所有订单上的贡献和除以「每单可见品类最高 IDF」之和。该值衡量捕获了多少中长尾权重，和普通覆盖率使用不同分母。

## 四、业务相关性和规则库多样性

| 配置 | 金额加权覆盖 | 不同后件数 |
| --- | ---: | ---: |
| P1 | 72.64% / 63.60% | 21 / 15 |
| P2 | 76.56% / 68.91% | 12 / 14 |
| P3 | 70.26% / 65.97% | 11 / 9 |
| P4 | 77.08% / 69.01% | 12 / 14 |
| P5 | 77.81% / 69.63% | 12 / 13 |

金额加权覆盖 = 至少完整命中一条规则的订单毛购买金额之和 ÷ 全部合格订单毛购买金额。每单金额只计一次。这里使用已处理篮子文件的整单 gross_purchase_amount，反映覆盖与订单购买额的关系。后件多样性按不同后件品类计数，CSV 另报实际触发和进入 Top‑5 的后件种数。

## A1 对照与共享口径

P5 / 100 限群 L 与 100 套 A1。

| 指标 | L | A1 中位 | A1 ≥ L |
| --- | ---: | ---: | ---: |
| 触发准确率 | 38.88% | 38.97% | 54/100 |
| Hit@5 | 17.44% | 16.98% | 9/100 |
| Added Value 中位 · pp | +14.33 | +15.08 | 100/100 |
| 跨期 confidence 变化 · pp | -5.48 | -5.47 | 51/100 |
| 群内 − 群外 confidence · pp | +0.93 | +0.32 | 7/100 |
| 群内 − 群外 Added Value · pp | +0.95 | +0.58 | 19/100 |
| 金额加权覆盖 | 69.63% | 68.21% | 0/100 |

P5 / 100 的 L 共享 Hit@5 为 **22.06%**，与 G 的 **22.08%** 接近。共享规则按方向规则去重，所有订单可尝试所有规则。这里使用原始 Validation 名单，不做残差补满。所有预算和口径的 A1 逐种子结果已保存，达到或超过次数含并列。
