# 1123 推荐收益来源 · 历史 Test 补测

沿用 1123 的冻结 A 快照、taxonomy_v1、2011-06-01 至 2011-12-01 左闭右开 Test 与固定遮挡。比较在同一 Test 订单上完成。1123 原 Test 已报告，本轮为补测。现有 P5／120 的 G/L/A1 对照在原目录。

## 评价安排

| 对照 | 主比较 | 固定项 |
| --- | --- | --- |
| L1 条件热门 | G120＋L1 条件热门 vs G120＋全局热门 | 1123 冻结的 120 个无向组合及其方向，规则优先、置信度排序，只有兜底榜不同 |
| 扩大全局池 | 融合 G200 vs 融合 G100 | 复用 1122 P5 的有向规则顺序、折扣聚合和 L1 条件先验，只增加 G 第 101–200 条的分数。另报 G100 规则优先与 G100 融合的差异，方便识别重排的作用 |
| 用个人历史选商品 | 融合 G200 的顾客历史 SKU vs 同一品类名单的 Discovery 热门 SKU | 每个推荐品类一个 SKU，最多五个。主比较是在有 ID 的可遮挡 Test 订单上，附全店与历史顾客分项。报告固定历史版本 |

L1 桶用可见 L2 所属大类多数票，平局按 L1 ID。用 1122 的固定遮挡为 Discovery 的 7,521 单建立条件分布，使用全局 L2 频率进行强度 30 的平滑。Test 全部方法共用原 1123 的遮挡，候选品类排除可见 L2，候选不足五项时保留可用项。

融合使用 1122 已选权重，头部 100 条权重 1，追加尾部 100 条权重 0.25，L1 概率权重 0.25。每个块对同一后件保留最强匹配置信度和前件不重叠的第二条证据，以 1122 的折扣公式聚合。前 100 条与后 100 条分别聚合。该对照的单位是有向规则，和 L1 对照的无向组合预算各有定义。

热门 SKU 按 Discovery 的固定 7,521 单内每个 SKU 的购买订单数排序，并列按 SKU。顾客历史中，同一 SKU 每单只计一次，按顾客在该品类历史购买单数、最近购买时间、Discovery 热门排名、SKU 决定一项。主方案只用**严格早于当前订单时间**的交易，同一时间的其他订单不可见。冻结版只用 2010-12-01 前的交易。没 ID 或预测品类无个人历史时回退热门。商品命中要求被遮品类实际出现过的 SKU 至少有一个在五项内。

每项报告 Hit@5、新增／丢失／净增命中及 2,000 次配对重抽 95% 区间。已识别订单按顾客抽，匿名订单按单独立分层重抽。记录所有可遮挡订单、SKU 主样本和真实历史可用数。运行前从 Discovery 写出两套 G 清单、L1 条件表及输入校验，随后才读取 Test 用于评价。

## 复算

在本目录运行 `python -X utf8 -B run.py freeze`，再运行 `python -X utf8 -B run.py test`。默认输出至 `results/`，也可用 `--out` 指定新目录。目录位置为 `1123/test_utility/`。读取相邻 `repository`、`1122`、`1123/results` 的输入。结果只导出汇总统计、公开规则与冻结记录。
