# 1123 四项补测协议

使用 1123 原始 Profile 标签、固定 P5／120 和冻结 G/L。阶段限定在 Profile、Discovery、Validation。

1. 品类差异与保持。对两期的 Profile 顾客订单，按无向二／三品类组合的订单支持率计算 Bray–Curtis。两期共用 Discovery 中至少出现 20 单的组合。主报群对群外的等权均值，另报群间两两平均、真实逐群距离和 L2 画像跨期自匹配。比较 S、A1、B2，各 100 套。差异保持主报各期真实值减随机中位数。
2. B2。依 B 分支登记使用 5 档历史订单数和 3 档 Profile 平均篮子大小交叉分层，共 15 个格子。平均篮子大小按每单不同 SKU 数。并列按冻结顾客顺序，用秩分三等份。各层内打乱标签，种子为 1000–1099，逐格保持每群人数。用 P5／120 重建 300 个 B2 规则库，评价全店覆盖、有 ID 订单的可靠覆盖、质量通过率和全店可遮挡订单的 Hit@5。
3. G 贪心。从与 G 相同的完整 Discovery P5 候选中为每个无向组合保留原排名最高的方向。每一步取 Discovery 新覆盖单数最大的候选，平局按原排名，到 120 个为止。Validation 比较其与普通 G、三套真实 L，并列规则重叠和独有命中。
4. 稳定性与缩放。对每种分群，在 Profile 做 50 次共同随机种子的 80% 不放回抽样，重拟合后对全体预测，报告相对全量模型的 ARI 与全量轮廓系数。缩放敏感性仅将 z-score 改为 RobustScaler，保持特征、变换、K、样本、规则预算及评价一致，再做 Discovery→Validation。报告新旧分区 ARI 与规则库指标。

补测的可靠覆盖使用每套系统的固定 120 条名单做 BY，原 G/L/A1 也在同一口径下重算。1123 原 Validation 网格保留其原来的大校正家族。区间和随机比较作描述。原始冻结及历史 Test 输出沿用已保存版本。
