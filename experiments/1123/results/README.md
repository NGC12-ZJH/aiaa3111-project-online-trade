# 1123 三种分群完整结果

在同一批订单和同一规则容量下比较三种分群。Validation 统一选出 **P5／120**，Test 评价冻结的 **304 套**规则库，属于历史 Test 补充评价。详见 [实验协议](../README.md)。

## Profile 分群与 Discovery 组库

三种分群各使用 2,684 名 Profile 顾客。价格分位线为 £1.65 和 £3.43。Discovery 挖掘样本为同一批 7,521 单，核对原纯 RFM、A1 与全局 G 的 153,000 个入库位置。

| 分群方法 | 三群 Profile 顾客数 | 三群 Discovery 订单数 |
| --- | --- | --- |
| 纯 RFM | 700／1,263／721 | 801／2,173／4,547 |
| RFM＋采购形态 | 1,225／427／1,032 | 1,649／758／5,114 |
| 纯采购形态 | 406／457／1,821 | 819／1,348／5,354 |

顾客分区的一致程度（ARI）为纯 RFM vs RFM＋采购形态 0.241，纯 RFM vs 纯采购形态 0.009，RFM＋采购形态 vs 纯采购形态 0.265。
