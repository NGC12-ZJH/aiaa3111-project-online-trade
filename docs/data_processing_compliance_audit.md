## 数据质量现象及处理

以下是源数据现象，不是未处理的静默错误：

| 现象 | 规范来源数量 | 比例 | 处理及风险控制 |
|---|---:|---:|---|
| 缺失客户 | 235,287 | 22.5188% | 保留证据和有效商品篮；排除需要历史标签的主 G/L/R 比较 |
| 缺失描述 | 4,275 | 0.4092% | 商品键使用 `stock_code`；描述仅用于解释和审计 |
| 取消订单 | 19,165 | 1.8342% | 不进入正向篮；符合条件时进入退款金额 |
| 负数量 | 22,557 | 2.1589% | 不进入正向篮；符合条件时进入退款金额 |
| 零价格 | 6,024 | 0.5765% | 主版本不进入篮或 RFM；另存敏感性审计 |
| 负价格 | 5 | 0.0005% | 排除主篮和标准金额，保留审计 |
| 非商品编码 | 5,831 | 0.5581% | 按版本化编码表排除，另存特殊编码审计 |
| 后续完全重复候选 | 11,812 | 1.1305% | 主版本删除其金额/篮影响，同时保留含重复敏感性金额 |

83 个订单含多个时间戳，最大跨度 540 秒；全部未跨实验时期。极端数量和金额未被静默删除，均保存在审计文件。
